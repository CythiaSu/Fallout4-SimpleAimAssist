# SimpleAimAssist 1.2.4

修复未进入战斗的敌对目标无法被锁定的问题。  
Fixed an issue where hostile targets could not be locked before entering combat.

本版本保留 1.2.3 的全部功能，包括独立锁定、近战/远程距离区分、目标标记、MCM 配置和手动移动准星后返回锚点。  
This release retains all features from 1.2.3, including independent lock-on, separate melee/ranged distances, target markers, MCM settings, and delayed return to the aim anchor after manual crosshair movement.

“允许锁定未进入战斗的敌人”仍属于实验功能，默认关闭。  
“Allow Locking Out-of-Combat Hostile Targets” remains experimental and is disabled by default.
